Модуль 1: Game Loop & Network (Сервер Go)
Авторитарный тик-сервер. Запускает игровой цикл (например, 60 тиков в секунду).

Принимает от клиента только инпуты (нажата клавиша W, мышь на координатах X:Y).

Сам считает коллизии, движение, траектории пуль.

Раз в тик отправляет клиенту упакованный бинарный пакет со всеми координатами объектов на карте.

Модуль 2: Клиентский Рендеринг (TS + Pixi.js/Phaser)
Абсолютно "глухой" и "тупой" клиент.

Получает массив координат от Go.

Интерполирует (сглаживает) движение, чтобы мобы не дергались.

Отрисовывает темную сетку, неоновые эффекты матового стекла и шейдеры для лазеров.

При нажатии ESC отправляет запрос на сервер и открывает оверлей со статами.

Модуль 3: ECS (Entity Component System) на сервере
Самый важный модуль для рогалика, где на арене одновременно находятся 500+ объектов. Моб, игрок, пуля — это просто ID (Entity), у которого есть компоненты: PositionComponent, HealthComponent, FactionComponent (игрок/вирус/дрон). Система урона просто пробегает по сущностям и вычитает логику. Никаких тяжелых циклов.

Модуль 4: Система Волн и Прогрессии карты
Замкнутая арена. С 1 по 50 волну сервер плавно меняет переменные:

Spawn_Rate (частота появления мобов увеличивается).

Camera_Scale (клиенту отправляется команда на плавный зум-аут camera.zoom -= 0.01 с каждым уровнем прошивки, чтобы игрок видел больше пространства, так как скорость и дальность стрельбы растут).

На 50 волне спавнится Главный Архитектор ИИ (Финальный Босс). При его смерти Go шлет триггер GAME_OVER_SUCCESS.

Спринт 1 (Go Core): Написание базового UDP/WebSocket сервера на Go. Настройка ECS-движка (простое перемещение точки по пустой арене).

Спринт 2 (TS Render): Подключение Pixi.js. Отрисовка сетки, синхронизация движения точки с сервером без задержек.

Спринт 4 (Progression & UI): Система уровней, генерация 3 карт выбора при Level Up. Окно статов на ESC. Справа выводим слоты инвентаря.

Спринт 5 (Loot & Boss): Архитектура дропа предметов. Реализация класса Некромант (перехват контроля над сущностями). Настройка 50-й волны с Боссом. Косметический (fix) багов.
